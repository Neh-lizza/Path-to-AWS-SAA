The roadmap / my course outline

My AWS learning path.

This learning path follows the five sections of my current AWS course, from the introduction to AWS networking with Amazon VPC. Each stage builds the knowledge needed for the next topic.

01

SECTION 01

Introduction

Begin with the basic concepts needed to understand cloud computing and the AWS environment.

  • Introduction to cloud computing
  • What Amazon Web Services (AWS) is
  • Why organizations use cloud services
  • Basic AWS concepts and terminology
Read cloud fundamentals →
02

SECTION 02

AWS Organizations, SCPs, and Control Tower

Learn how AWS accounts are grouped, managed, and governed, particularly when an organization uses multiple accounts.

  • AWS Organizations and account management
  • Organizational units (OUs)
  • Service Control Policies (SCPs)
  • How SCPs limit the maximum permissions available to accounts
  • AWS Control Tower and centralized governance
Read about SCPs →
03

SECTION 03

AWS Identity and Access Management (IAM)

Understand how AWS identifies users and services, grants permissions, and protects access to resources.

  • IAM users, groups, roles, and policies
  • Authentication and authorization
  • Allow and deny permissions
  • Identity-based and resource-based policies
  • The principle of least privilege
  • IAM roles and temporary credentials
Users vs roles →
04

SECTION 04

Amazon S3 and Storage Gateway

Study AWS storage services, how data is stored in the cloud, and how on-premises systems can connect to AWS storage.

  • Amazon S3 buckets and objects
  • S3 storage classes and access permissions
  • Bucket policies and data protection
  • Versioning and lifecycle management
  • Static website hosting with Amazon S3
  • AWS Storage Gateway and hybrid cloud storage
Explore the S3 project →
05

SECTION 05 / PART 1

AWS Networking: Virtual Private Cloud (VPC)

Learn how to create a logically isolated network in AWS, divide it into subnets, direct traffic, and control network access.

  • What a VPC is and why it is needed
  • CIDR notation and VPC IP address ranges
  • IP addressing and subnetting
  • Public and private subnets
  • Route tables and routing
  • Internet Gateways and internet connectivity
  • NAT Gateways and outbound internet access
  • Security groups and network ACLs
Study CIDR and subnetting →Security groups vs NACLs →
