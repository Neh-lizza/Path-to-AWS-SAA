Adding a new post

  1. Copy any file in articles/ and rename it, for example my-new-post.html.
  2. Replace the title, description, and body text.
  3. Copy one <article class="article-card"> block in blog.html, then update its link, data-category, and data-search.
  4. Upload the changed files to your S3 bucket.
