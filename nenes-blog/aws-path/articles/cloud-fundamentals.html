What cloud computing actually means

Before any service names, start with the idea: renting computing power over a network, on demand, instead of owning every server.

The core idea

Cloud computing means using computing resources, such as servers, storage, and databases, over the internet and paying for what you use. Instead of buying hardware and waiting weeks, you request resources and have them in minutes.

What makes it different

  • On-demand self-service: you create resources yourself, without a purchase order.
  • Elasticity: scale up for a busy day and down afterwards.
  • Pay as you go: costs follow usage rather than upfront hardware.
  • Global reach: deploy close to your users in many Regions.

Regions and Availability Zones

A Region is a geographic area. Each Region has multiple Availability Zones: isolated data center groups with their own power and networking, connected by fast links. Spreading a workload across zones keeps it running if one zone fails.

Shared responsibility

AWS is responsible for security of the cloud: facilities, hardware, and the core services. You are responsible for security in the cloud: your data, identities, and configuration. A public S3 bucket is a configuration issue, not an AWS failure.

Why organizations use it

Faster experiments, less upfront cost, easier growth, and access to managed services. The trade-off is that cost and security now need active attention.
