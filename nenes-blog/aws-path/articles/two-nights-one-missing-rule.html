Two Nights, One Missing Rule

I was so happy when I finally got this working!

NETWORKING3 MIN READ

The story

I spent almost two nights trying to get a simple webpage running on an EC2 instance. I followed so many tutorials. Everyone seemed to get it working effortlessly, but mine just wouldn't cooperate.

Apache wouldn't install, the webpage wouldn't load, and I kept going back to check the same configurations.

At some point, I started questioning everything. Was it my User Data script? My subnet? My route table? My security group?

What was wrong

Turns out, I had overlooked one little thing: outbound rules.

I had configured inbound traffic to allow HTTP requests, but my security group had no outbound rules. My instance couldn't reach the internet to download the packages it needed.

One missing rule. Almost two nights.

I also discovered that I was using commands from an Amazon Linux tutorial on an Ubuntu instance. Another little lesson!

The fix

  1. Open the instance's security group and choose Outbound rules.
  2. Add a rule that allows outbound traffic (for a lab, All traffic to 0.0.0.0/0, which is what a new security group allows by default).
  3. Use the package manager that matches your operating system:
OSInstall Apache
Amazon Linuxsudo dnf install -y httpd
Ubuntusudo apt update && sudo apt install -y apache2

The lesson

Anyway, the page finally loaded, and I was genuinely excited to see it work.

Cloud computing is slowly teaching me that sometimes the real learning starts when things refuse to work.

On to the next practical!
